# 📱 Mobile Application Development — PKCERT Internship

This repository documents my weekly progress and hands-on projects completed during my Mobile Application Development internship at PKCERT. Each week's work builds on the previous one, covering everything from Flutter environment setup and Dart fundamentals to building fully functional cross-platform mobile applications using Flutter and Dart.

## 🎯 About This Internship

As part of this internship, I am gaining practical experience in mobile app development using Google's Flutter framework — learning industry-standard tools, workflows, and best practices for building responsive, high-performance applications for Android and iOS from a single codebase.

## 🛠️ Tech Stack

- **Framework:** Flutter
- **Language:** Dart
- **Backend:** Firebase (Auth, Firestore)
- **AI:** Google Gemini API
- **Monetization:** Google AdMob
- **IDE:** Visual Studio Code / Android Studio
- **Version Control:** Git & GitHub

## 📂 Weekly Projects

| Week | Topic | Description |
|------|-------|-------------|
| Week 1 | Environment Setup & First App | Set up the Flutter development environment, learned Dart basics (variables, null safety, functions, OOP), core Flutter widgets, and built/ran a first Flutter app on an Android emulator. |
| Week 2 | Widgets & Layouts | Built a fully functional Profile Screen UI using `Container`, `Row`, `Column`, `Expanded`, `ListView`, and `ElevatedButton` — applying core Flutter layout widgets, custom asset images, and card-style theming. |
| Week 3 | Navigation, State Management & APIs | Built a multi-screen app covering `Navigator.push`/`pop`, passing data between screens, and shared state management with **Provider**. Extended it to consume a public REST API — parsing JSON into Dart models, displaying data with `FutureBuilder`, handling loading/error states, and pull-to-refresh with `RefreshIndicator`. |
| Week 4-6 | SpendWise — Full Expense Tracker App | Built **SpendWise**, a complete cross-platform expense-tracking app: Firebase Authentication, local SQLite storage, Cash In/Out tracking with smart AI categorization, an animated onboarding dashboard, AI-powered features (voice-to-expense, receipt scanning via camera + Gemini Vision, an in-app AI chat assistant "Wise" for spending Q&A, and a rewarded-ad "Deep AI Insight" analysis), PDF report export/share, budget alerts, and Google AdMob monetization (banner, interstitial, and rewarded ads). |

*(This table will be updated weekly as new projects are added.)*
